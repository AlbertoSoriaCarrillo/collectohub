# Roadmap

## Fase 0 - Preparación

- Crear repositorio.
- Añadir documentación de Codex.
- Definir arquitectura.
- Definir entidades principales.
- Definir tareas iniciales.

## Fase 1 - Backend MVP

Objetivo: validar el núcleo de producto.

Incluye:

1. Proyecto Spring Boot base.
2. PostgreSQL + Liquibase.
3. Seguridad JWT.
4. Usuarios y roles.
5. Tiendas.
6. Miembros de tienda.
7. Catálogo maestro.
8. Inventario.
9. Colecciones.
10. Reservas sin pago.
11. Recomendaciones básicas.
12. Tests.
13. Swagger.
14. Docker Compose.
15. GitHub Actions.

## Fase 2 - Frontend MVP

Incluye:

1. Angular.
2. Angular Material.
3. Login/registro.
4. Catálogo.
5. Colecciones.
6. Panel de tienda.
7. Reservas.
8. Recomendaciones.
9. Multiidioma castellano/inglés.
10. PWA.

## Fase 3 - Social básico

Incluye:

- Seguir usuarios.
- Seguir tiendas.
- Publicaciones.
- Comentarios.
- Likes.
- Reseñas.
- Fotos de perfil.
- Fotos de colección.

## Fase 4 - Marketplace avanzado

Incluye:

- Pagos.
- Envíos.
- Carrito.
- Pedidos.
- Facturación básica.
- Comisiones.
- Venta entre usuarios.
- Intercambios.

## Fase 5 - Comunidad avanzada

Incluye:

- Chat.
- Multimedia en publicaciones.
- Vídeos.
- Audios.
- Creadores de contenido.
- Directos.
- Eventos.
- Gamificación.

## Fase 6 - Escalabilidad

Incluye:

- OpenSearch.
- Almacenamiento cloud.
- Notificaciones push.
- App móvil nativa si tiene sentido.
- Recomendaciones avanzadas.
- Cercanía geográfica.
